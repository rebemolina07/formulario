Formularios en HTML

Texto

Campo de texto basico: simple, con placeholder, obligatorio (required), de lectura (readonly) y deshabilitado (Disabled).











Contacto

Campos especializados para datos de Contacto: contraseña, correo electronico, telefono, url, cada uno con su propio teclado y validacion en el navegador









Numericos

Campos para valores numéricos: un número con límites (min/max) y un deslizador (range) para elegir un valor dentro de un rango.





Fecha y Hora

Selectores nativos de fecha y hora: fecha, fecha y hora combinadas, hora, semana delaño y mes.











Seleccion

Controles de selección: elegir un color, marcar una casilla, elegir una opción de un grupo de radios y subir un archivo.







Listas desplegables

Listas desplegables con el elemento select: una opción simple, una con valorpreseleccionado (selected), una agrupada con optgroup, una de selección múltiple (multiple) y unadeshabilitada (disabled).
